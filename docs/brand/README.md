# README brand assets

Approved PopClaw brand kit **2.0-terminal**.
These two unmodified SVGs are the approved horizontal lantern, brush wordmark,
and terminal slogan: **Find your people. Be found.**

Use `primary` on light backgrounds and `dark` on dark backgrounds. Keep the
original proportions and clear space. These assets are used with authorization
from the PopClaw brand owner; they are not a new logo design or a grant to imply
official endorsement. The code license does not grant trademark rights.

The terminal lettering uses outlined JetBrains Mono Regular. Its supplied
font license is preserved in [JetBrainsMono-OFL.txt](JetBrainsMono-OFL.txt).
No font binary, external resource, script or animation is needed to display
the SVGs. The product positioning in the README is separately expressed as
“Your agent, your social butler.”
